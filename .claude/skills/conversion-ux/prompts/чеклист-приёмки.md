# Чеклист приёмки страницы

Проходить перед показом заказчику и перед выкаткой. Любое «нет» в блоке «Красная зона» = не сдавать.

---

## Красная зона (блокирующая)

- [ ] На странице нет ни одного выдуманного факта, отзыва, кейса, цифры, награды, логотипа
- [ ] В портфолио только свои работы
- [ ] Ни один сгенерированный человек не выдаётся за сотрудника, клиента или эксперта
- [ ] Ни одно сгенерированное изображение не выдаётся за реальный товар или объект
- [ ] Чекбокс согласия на ПДн не предзаполнен
- [ ] Согласие на данные и согласие на рекламу — разные чекбоксы
- [ ] Юридические тексты взяты у юриста, не сочинены
- [ ] Таймеры и «осталось N мест» соответствуют реальности
- [ ] У каждой гарантии есть публичные условия по ссылке
- [ ] Мобильная версия не сломана: нет горизонтального скролла, обрезанных кнопок и текста

## Первый экран

- [ ] За 5 секунд ясно: что, для кого, что получу, что нажать
- [ ] Заголовок нельзя дословно поставить конкуренту
- [ ] Одна главная кнопка
- [ ] Под кнопкой снят хотя бы один страх
- [ ] Минимум два вида доказательств выше сгиба
- [ ] Изображение показывает предмет или результат
- [ ] Кликабельный телефон + мессенджеры + часы работы (RU-услуги)
- [ ] Следующий блок частично виден до прокрутки

## Смысл и структура

- [ ] По одним заголовкам секций читается вся история
- [ ] Нет заголовков-ярлыков («Преимущества», «Наш процесс», «О компании»)
- [ ] То, за чем пришли (работы, цены), — во второй-третьей секции
- [ ] Есть второе, более лёгкое целевое действие
- [ ] «Как работаем» — 3–4 шага, не больше
- [ ] Нет секций, которые ничего не доказывают и ничего не снимают
- [ ] Речь о клиенте («вы получите»), а не о себе («мы готовы»)

## Доказательства

- [ ] Доказательство рядом с каждой кнопкой
- [ ] У отзывов есть имя, фото и проверяемый источник
- [ ] Есть отзыв под каждый типовой страх
- [ ] Отзывы не спрятаны в карусель на мобильном
- [ ] Логотипы сопровождаются цитатами или контекстом
- [ ] В подвале — юрлицо, ИНН, ОГРН

## Форма и CTA

- [ ] Полей ровно столько, сколько используется
- [ ] Сначала вопросы о задаче, потом контакты
- [ ] Одна колонка, лейблы всегда видны
- [ ] Выбор вместо ручного ввода везде, где возможно
- [ ] Пароля на лид-форме нет
- [ ] Ошибки конкретные, рядом с полем, введённое сохраняется
- [ ] Валидация на своём шаге, «Далее» не пропускает пустое обязательное
- [ ] Есть выбор канала ответа
- [ ] Кнопка отправки не перекрыта клавиатурой и sticky-панелью
- [ ] Настроена страница «Спасибо» и цель в аналитике

## Мобильный и скорость

- [ ] Мобильный порядок блоков спроектирован отдельно
- [ ] Одна кнопка в липкой панели
- [ ] Проверено на 320 px, в landscape и с открытой клавиатурой
- [ ] LCP ≤2,5 с, INP ≤200 мс, CLS ≤0,1 на мобильном
- [ ] Тяжёлые виджеты (чат, коллтрекинг) грузятся отложенно
- [ ] Cookie-баннер не сдвигает контент
- [ ] Видимый фокус, контраст ≥4.5:1, форма проходится с клавиатуры

## Аналитика

- [ ] Цели: отправка формы, клик по телефону, клик по мессенджеру, страница «Спасибо»
- [ ] Подключены Метрика/GA4 и Clarity (или Вебвизор)
- [ ] Для статей — событие дочитывания и клика по инлайн-CTA
- [ ] Если звонок значим — подключён коллтрекинг
