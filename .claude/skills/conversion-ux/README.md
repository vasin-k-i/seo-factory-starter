# Конверсионный UX — рабочая система

Свод правил конверсионного дизайна для своих и заказных проектов. Собран 2026-08-11
из первичных исследований (Baymard, NN/g, Unbounce, Zuko, web.dev), вендорских бенчмарков
(Interact, Riddle, Goldcast, Popupsmart), 16 разобранных видео-разборов (EN + RU) и парсинга
живых российских лендингов.

Цель — не «красивее», а **больше заявок и продаж с того же трафика**, при этом без вранья
и без нарушения 152-ФЗ.

---

## Как пользоваться

**Верстаю / рисую страницу.** Читать перед началом:
`system/00-ЯДРО.md` → `system/01-первый-экран.md` → файл своего типа страницы → `system/ANTI.md`.
Параллельно — скилл `anti-neuroslop` (он про «не выглядеть как нейронка», этот пакет — про деньги).

**Вшиваю в промпт нейросети.** Взять `prompts/system-prompt.md` целиком — это сжатая версия
на ~1 200 слов, готовая к вставке в системный промпт.

**Принимаю работу.** `prompts/чеклист-приёмки.md`.

**Чиню существующий сайт.** Сначала `system/12-измерение-и-тесты.md` — без карт кликов
и записей сессий правки делать нельзя.

## Метки доказанности

В тексте каждое существенное утверждение помечено:

- **A** — исследование с раскрытой методикой или контролируемый эксперимент. Опираться можно.
- **B** — вендорский бенчмарк по своей платформе. Порядок величины верный, абсолют — нет.
- **C** — практика агентств и экспертов без публичной методики. Гипотеза для теста.

Всё, что уровня «продавец рассказывает про свой продукт», в систему не бралось.

⚠️ Отдельно: русскоязычная выдача по «средняя конверсия лендинга по отраслям» почти целиком
состоит из SEO-фабрик с сочинёнными таблицами. Ни одна такая цифра сюда не попала.
RU-цифры — только из первоисточников (ЦБ, Яндекс, Data Insight) или из наблюдения за живыми
страницами.
